# TimeWise

TimeWise is a Next.js application designed to help users track their time effectively and receive AI-powered recommendations for optimizing their productivity.

## Core Features

- **Firebase Authentication**: Secure user login and registration with email and password.
- **Timer**: A simple and intuitive timer to start, pause, resume, and stop tracking time for different tasks.
- **Firestore Data Storage**: All time logs are securely stored in Firestore, with data partitioned by user.
- **Session History**: View a comprehensive list of all past time tracking sessions.
- **AI Recommendations**: Get personalized daily/weekly summaries and actionable advice on improving time management, powered by Google's Gemini model.
